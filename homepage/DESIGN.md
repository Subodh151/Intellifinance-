## Brand & Style

This design system establishes an authoritative, institutional, and meticulously engineered environment tailored for high-stakes financial intelligence. The aesthetic merges **Corporate Modernism** with an ultra-clean **Data-Dense SaaS** architecture. It prioritizes confidence, analytical clarity, and effortless visual parsing over decorative excess.

### Personality & Emotional Response
- **Authoritative & Institutional:** Evoking the quiet precision of top-tier investment banking workstations blended with modern enterprise software.
- **Calm Under Pressure:** Dark slate anchoring layers counterbalance crisp white foreground planes to prevent cognitive fatigue during prolonged analysis sessions.
- **Instant Scannability:** Deliberate typographic contrast and disciplined semantic accents ensure anomalies, positive vectors, and critical KPI shifts stand out instantly.

### Design Principles
1. **Content Over Ornament:** Chrome is minimal; interfaces yield space to data metrics, multi-series trendlines, and ledger structures.
2. **Subtle Tactility:** Depth is communicated through calibrated ambient drop-shadows and micro-borders rather than saturated gradients or heavy surfaces.
3. **Data Integrity:** Strict vertical baselines, monospaced tabular numerals, and dedicated visual slots for currency denominations and percentage deltas.

## Colors

The palette leverages high-contrast slate foundations, crisp neutral backgrounds, and strictly semantic indicator accents. The interplay between dark foundation slates and pure white surfaces gives cards and panels exceptional presence.

### Palette Architecture
- **Primary Foundation (`#0F172A` - Slate 900):** Used for commanding typography, primary buttons, navigation chrome, and core brand anchors.
- **Secondary Accent (`#4F46E5` - Indigo):** Reserved for institutional trust points, active interactive states, primary focus rings, selected chart series, and system intelligence insights.
- **Tertiary Positive (`#10B981` - Emerald) & Mint (`#34D399`):** Dedicated entirely to positive growth indicators, revenue accruals, upward delta badges, and favorable metric forecasts.
- **Warning Amber (`#F59E0B`):** Flags impending liquidity thresholds, budget warnings, and reconciliation cautions.
- **Coral Red (`#EF4444`):** Strictly deployed for negative trends, anomaly spending detection, margin erosions, and critical risk flags.
- **Neutral Canvas Hierarchy:**
  - App Canvas / Page Background: `#F8FAFC` (Slate 50)
  - Card & Surface Fill: `#FFFFFF`
  - Subtle Dividing Borders: `#E2E8F0` (Slate 200)
  - Secondary Text / Meta Labels: `#64748B` (Slate 500)
  - Tertiary / Disabled Borders: `#CBD5E1` (Slate 300)

### Color Usage Guidelines
- Never use the tertiary emerald or coral red as decorative brand fills; they are strictly diagnostic.
- Use full opacity `#0F172A` for primary headlines and data values. Secondary metrics transition to `#4F46E5` or `#64748B` to establish distinct visual tiers.

## Typography

The typographic system couples **Plus Jakarta Sans** for prominent headers, metric cards, and navigation titles with **Inter** for dense tabular ledgers, parameters, and form controls.

### Tabular Numbers & Font Features
- All numeric instances across charts, financial statements, ledgers, and metric readouts must activate CSS tabular lining features: `font-feature-settings: "tnum" 1, "cv05" 1, "cv02" 1`.
- This ensures columns of balances, percentages, and currencies align vertically down to the decimal point without horizontal jitter.

### Hierarchy & Legibility
- **Labels & Micro-headers:** `label-sm` utilizes an uppercase or elevated tracking treatment (`0.04em`) with slate-500 coloring for section categories, metric card prefixes, and column headers.
- **Negative Space Calibration:** Tight letter-spacing on headline metrics prevents numbers with commas and currency symbols from breaking visual cohesion.

## Layout & Spacing

The layout is built around a modern SaaS **fluid-responsive grid** structured for high-density analytic dashboards and responsive multi-pane splits.

### Grid & Breakpoints
- **Desktop (1280px+):** 12-column grid, `gutter: 1.5rem`, `margin: 2rem` or clamped max-width container at `1600px`. Standard fixed sidebar navigation (260px) paired with an expansive flexible canvas.
- **Tablet (768px - 1279px):** 8-column grid, `gutter: 1rem`, `margin: 1.5rem`. Collapsible sidebar icon rail (64px) with multi-row dashboard card reflows.
- **Mobile (Under 768px):** 4-column grid, `gutter: 0.75rem`, `margin: 1rem`. Full stack reflow for key performance blocks, horizontal scrolling for dense data tables, and bottom-sheet drawers for filtering menus.

### Spacing Principles
- Use `space-sm` (0.5rem) and `space-xs` (0.25rem) strictly for internal atom groupings: badge padding, button text-to-icon gaps, and input field label offsets.
- Card padding defaults to `space-lg` (1.5rem) on desktop analytics panels, compressing to `space-md` (1rem) on mobile viewports.

## Elevation & Depth

Visual hierarchy relies on **ambient shadows coupled with subtle hairline outlines**, deliberately avoiding heavy, blurry cast shadows. This creates a crisp, surgical depth model.

### Elevation Hierarchy
- **Level 0 (Canvas Base):** Flat `#F8FAFC` foundation. No shadow.
- **Level 1 (Card & Dashboard Panels):** 
  - Fill: `#FFFFFF`
  - Outline: `1px solid #E2E8F0`
  - Shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`
- **Level 2 (Hover States, Metric Focus, Dropdown Menus):** 
  - Fill: `#FFFFFF`
  - Outline: `1px solid #CBD5E1`
  - Shadow: `0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)`
- **Level 3 (Modals, Slide-over Decision Drawers, Popovers):**
  - Fill: `#FFFFFF`
  - Outline: `1px solid rgba(15, 23, 42, 0.08)`
  - Shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.06)`

### Ambient Lighting Tone
Shadows use low-opacity tinted slate (`rgba(15, 23, 42, ...)`) rather than absolute black, keeping cards seamlessly grounded in the cool slate universe without appearing dirty.

## Shapes

The design system utilizes **Rounded Level 2** geometry, striking an intentional balance between enterprise seriousness and modern product design.

### Geometry Specifications
- **Controls & Form Elements:** `0.5rem` (`rounded-md`) for text inputs, standard buttons, select triggers, and search bars.
- **Cards & Data Containers:** `0.75rem` to `1rem` (`rounded-lg` / `rounded-xl`) for main analytic containers, data grids, and summary cards.
- **Tags, Status Chips & Pill Accents:** Fully rounded `9999px` (`rounded-full`) for status indicators, delta chips (`+14.2%`), category tokens, and user avatar pills.

## Components

### Buttons
- **Primary:** `#0F172A` background, white typography, `rounded-md`, height 40px (desktop), padding `0 1rem`. Micro-border: `1px solid #0F172A`. On hover: transition to `#1E293B`.
- **Secondary / Action:** `#FFFFFF` background, `#0F172A` text, `1px solid #E2E8F0`. On hover: `#F8FAFC` background with `#CBD5E1` border.
- **Accent (Institutional CTA):** `#4F46E5` background, white text, subtle hover lift and color transition to `#4338CA`.
- **Focus Rings:** All buttons exhibit an offset focus ring using `2px solid #4F46E5` with `2px` white outline offset.

### Chips & Badges
- **Pill Badges:** Fully circular (`rounded-full`), height 24px, padding `0.125rem 0.625rem`, typography `label-sm`.
  - *Positive Growth:* Emerald tint background (`rgba(16, 185, 129, 0.1)`), emerald text (`#047857`), paired with an inline upward delta vector.
  - *Anomaly / Negative:* Coral tint background (`rgba(239, 68, 68, 0.1)`), red text (`#B91C1C`).
  - *Neutral / Tag:* Slate tint background (`#F1F5F9`), slate text (`#475569`).

### Input Fields & Search Bars
- Standard input height 40px, `rounded-md`, background `#FFFFFF`, border `1px solid #CBD5E1`.
- Font: Inter `body-md`. Placeholder color `#94A3B8`.
- Active / Focus: Border changes to `#4F46E5` accompanied by an ambient indigo glow `box-shadow: 0 0 0 3px rgba(79, 70, 229, 0.15)`.

### Cards & Analytical Modules
- Background `#FFFFFF`, border `1px solid #E2E8F0`, corner radius `0.75rem`.
- Header zone partitioned by a bottom hairline (`border-b: 1px solid #F1F5F9`) with standard padding `1rem 1.5rem`.
- Data readouts within cards pair a tiny tracking label (`label-sm`, uppercase) with bold financial figures (`data-metric-lg` or `data-metric-md`) and an inline status chip.

### Checkboxes & Radio Controls
- Base size: 16x16px. Corner radius: 4px for checkboxes, circular for radios.
- Unchecked state: `1.5px solid #CBD5E1`, background `#FFFFFF`.
- Checked state: `#4F46E5` fill with pure white checkmark/dot vector.

### Data Grids & Ledgers
- Row height: 48px standard, 36px compact ledger view.
- Alternating subtle hovers (`#F8FAFC`) with immediate row highlight.
- Header row: `#F8FAFC` background, text in `label-sm` (`#64748B`), bottom border `1px solid #CBD5E1`.
- Cell dividers: zero vertical borders, horizontal separation using single `1px solid #F1F5F9`. Numeric columns must align right.

### Specialized Financial Additions
- **Anomaly Banner:** Thin `4px` left edge border in coral red (`#EF4444`), warm neutral card body, accompanied by quick-resolution actions.
- **Chart Tooltip Container:** Deep slate `#0F172A` background, white text, subtle backdrop blur, rendering real-time cursor coordinates and currency valuations with tabular numbers.
